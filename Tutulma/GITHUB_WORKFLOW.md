# Tutulma — GitHub Çalışma Düzeni

## Ana Dal
`main` çalışır ve doğrulanmış değişiklikler için kullanılacak.

## Commit
Commit mesajları yapılan işi açıkça anlatmalı.

## Klasörler
- `Tutulma/` — proje dokümanları
- `Tutulma/UnityProject/` — Unity kaynakları
- `Tutulma/UnityProject/Assets/` — Unity asset ve script yapısı

## Unity'den Sonra
Unity'nin ürettiği geçici klasörler ve yerel kullanıcı dosyaları GitHub'a gönderilmeyecek. Kaynak kod, sahneler, prefablar, materyaller ve gerekli proje ayarları sürümlenecek.

## Kural
Önemli değişikliklerden sonra main doğrulanacak. Başka dallardaki eski çalışmalar main'e doğrudan birleştirilmeyecek.
