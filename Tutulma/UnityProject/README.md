# Tutulma — Unity Project

Bu klasör, Tutulma oyununun Unity kaynak kodu için başlangıç noktasıdır.

## Kurulum
1. Unity Hub ile yeni bir 3D Unity projesi oluştur.
2. Bu klasördeki `Assets` klasörünü oluşturduğun Unity projesinin köküne kopyala.
3. Unity Editor'de projeyi aç.
4. İlk sahnede bir `Player` GameObject oluştur ve `PlayerController` scriptini ekle.
5. Kamera için `PlayerCamera` scriptini kullan.
6. Dünya başlangıcı için `WorldBootstrap` scriptini, Güneş anomalisi için `SunAnomaly` scriptini kullan.

## İlk hedef
- Oyuncu hareketi
- Kamera kontrolü
- Temel dünya kurulumu
- Güneş anomalisi için görsel/oynanış altyapısı

Unity'nin oluşturduğu `Library`, `Temp`, `Logs`, `obj` ve benzeri klasörler GitHub'a eklenmemelidir.
