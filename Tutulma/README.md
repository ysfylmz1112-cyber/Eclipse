# TUTULMA

Hikâye odaklı, yüksek kaliteli bilim kurgu/macera oyunu.

## Vizyon
Güneş tutulmasının ardından Güneş'te başlayan anomali Dünya'yı yaşanamaz hâle getirir. İnsanlık, Dünya'dan ayrılıp yeni dünyalar bulmak zorunda kalır. İnsanlığın karşısındaki en büyük tehdit ise çok daha ileri teknolojiye sahip uzaylı uygarlıklardır.

## Geliştirme
Proje sıfırdan kuruluyor. Sistemler aşamalı olarak eklenecek.
